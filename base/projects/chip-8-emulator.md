[Chip-8](https://en.wikipedia.org/wiki/CHIP-8) is an intepreted programming language from the 1970's.
Nowadays it is the "Hello World" of the emulating world. With only 35 opcodes implementing it is relatively easy.

I decided to work on my own little version in C# using OpenTK (OpenGL bindings for C#). I just put in a few minutes of work in whenever I'm waiting for my 3D prints to finish.

In the current state most opcodes are implemented and there's a few debugging tools.
However, it is not fully working as expected, so surely there's a few bugs I have to work out still.
