Rogue Blast was my first released game.
It was made in 48 hours for Ludum Dare 37.

It used the LÖVE framework. I wrote all the code. Created all the assets. And made the music (Which I _might_ have stolen).

This game was my first attempt at procedural generation in the form of generating the levels.
It also features a rich set of "items" to try feel like a rogue-like.

Overall I'd say it's really quite good for a first game
